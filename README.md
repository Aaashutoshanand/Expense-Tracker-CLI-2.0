# 💰 Expense Tracker 2.0 (Python CLI)

A simple yet powerful **Command-Line Expense Tracker** built in Python as part of my internship project.  
This application helps track daily expenses with categories, search functionality, and spending insights.

---

## 🚀 Features

- ✅ Add expenses with category and date  
- 📋 View all expenses  
- 🔍 Search expenses by category  
- 📊 Calculate total spending per category  
- 📅 Monthly spending analysis  
- 🔥 Identify top spending category  
- ❌ Delete expenses  
- 📈 Summary statistics (total, count, average)  

---

## 🧠 Concepts Used

- File Handling (CSV)
- Data Filtering & Aggregation
- Exception Handling
- CLI Menu Design
- Basic Data Analytics

---
